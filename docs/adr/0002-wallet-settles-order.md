# تسویه با کیف پول هم کار لابراتوار را شروع می‌کند

شارژ کیف پول با همان زرین‌پال فقط موجودی را زیاد می‌کند و سفارش را پرداخت نمی‌کند. پرداخت کامل سفارش از موجودی همان تسویه است: سفارش به check می‌رود و فاکتور صادر می‌شود. پرداخت ترکیبی از موجودی و درگاه نیست؛ اگر موجودی کمتر از مبلغ سفارش باشد، سفارش روی پرداخت زرین‌پال می‌ماند.
